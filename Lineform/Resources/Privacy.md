# Privacy

Lineform is local-first.

- Documents are ordinary Markdown or text files.
- Files stay local unless the user stores them in iCloud Drive or another synced folder.
- There is no account system.
- There is no analytics collection by default.
- There is no document upload.
- Text piped into the `lineform` command line tool is written to a local file in `~/Library/Application Support/Lineform/Piped/` and opened as a normal document. These piped files stay on your device and are automatically deleted after 7 days if they are not open.
