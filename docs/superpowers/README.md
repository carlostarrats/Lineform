# Historical design and implementation records

Files under `docs/superpowers/` are dated records of decisions, specifications, and implementation
plans. They are not current instructions and must not be executed as task lists.

For current behavior, read `AGENTS.md` and the relevant file in `docs/architecture/`. For releases,
use only `docs/release/app-store-release.md`.

Some records describe features or infrastructure that no longer exists, including the old
command-line helper, self-updater, direct-download packaging, and diagram-report service. Those
references explain historical decisions only; they do not describe the shipping app.
