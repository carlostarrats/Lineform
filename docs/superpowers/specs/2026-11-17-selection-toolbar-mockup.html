# Playlist case study

The first version of the playlist screen tried to do everything at once. It showed the queue, the history, and the recommendations side by side, and nobody could find the play button.

We cut it back to **one list** and a single primary action. Testing showed people started a playlist in half the time, and the support tickets about "where did my music go" stopped almost entirely.

Select any text above to see the toolbar.

Toolbar appears when you select text in the editing view; it floats just above the selection and goes away when the selection is cleared. Right-click keeps working exactly as it does now. Buttons: Comment (only when an AI is connected) · Heading (Title, Section, Heading 3–6, Body) · Bold · Italic · Strikethrough · Code · List (Bulleted, Numbered, Blockquote) · Link.

Comment card replaces the toolbar in place. The chip names your connected AI. Pick an action from the menu, or leave it on Custom to send only what you typed. Either way the result comes back as the usual suggestion you accept or reject; nothing changes until you accept. Return sends, Esc closes.
