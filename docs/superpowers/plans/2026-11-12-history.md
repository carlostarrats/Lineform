# History Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-passage version history for every Lineform user — right-click "Add to History", a
sidebar History row that exists only when the document has history, and a read-only History mode
for stepping through versions — with no data in the `.md` and automatic cleanup.

**Architecture:** A pure-Swift history engine (model, level classifier, anchor locator, document
engine) in `Lineform/Documents/`, persisted as one small JSON file per document under
`~/Library/Application Support/Lineform/History/` behind a protocol (template:
`DiagramLogStore`). The editor (TextKit 1 `LineformTextView`) draws History-mode tints, dimming and
dots the way it already draws search highlights, and routes History-mode input through
`doCommand(by:)`, `mouseDown`, and `shouldChangeText`. The sidebar gains a conditional `.history`
tab rendered by a new `HistorySidebarView`. `EditorContainerView` owns one
`DocumentHistoryController` per open document and wires reload, document swap, move and Save As.

**Tech Stack:** Swift 5, SwiftUI + AppKit, TextKit 1, XCTest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-12-bring-your-own-ai-design.md` (§5, §5.0, §5.1, §6, §7,
§8). Mockup: `docs/superpowers/specs/2026-11-12-history-mode-mockup.html`. This is plan 1 of 3;
plans 2 (Connect Your AI) and 3 (AI actions + review) build on the `HistoryAuthor.ai` and
`DocumentHistoryController.recordAccepted(...)` interfaces defined here.

## Global Constraints

- History is available with **no AI connected**. Nothing in this plan touches the network.
- Never write anything into the user's `.md`. Store: `~/Library/Application Support/Lineform/History/`.
- Nothing is stored until a version is actually kept.
- Three levels only, ordered and labelled **Paragraph · Sentence · Word** (rawValues
  `paragraph`, `sentence`, `word`; `title` localized — never localize the rawValue).
- Cleanup: file deleted → removed; passage not found → dropped; untouched **30 days** → dropped;
  Settings ▸ **Clear History** removes everything.
- History follows the file through rename, move, iCloud move and Save As. `FileIdentity` stays
  the definition of "already open" and is **not** modified.
- Normal writing shows **no** history markers. History mode is the only place history is drawn.
- Edits use the localized `shouldChangeText` → `textStorage.replaceCharacters` → `didChangeText`
  path, never `applyWholeTextReplacement`; preserve CRLF and BOM; align ranges to composed-character
  boundaries.
- Every sidebar sub-view takes `usesDarkChrome` threaded from the theme; never read
  `@Environment(\.colorScheme)`.
- Level switcher text: `.system(size: 12, weight: .medium)`, colour
  `OutlineSidebarView.tabTextColor(usesDarkChrome:isSelected:isHovered:)` (same as "Sort folders
  by"). Version rows reuse the Files-row fonts and `rowSelectionFillColor` /
  `rowSelectionLabelColor`. No new greys or blues in the sidebar.
- Text inside a history tint or the selection keeps **≥ 4.5:1** against the flattened page, on all
  five built-in themes (`Theme.builtIn`) and under Automatic Dark Mode; measured with
  `Theme.contrastRatio`.
- All chrome strings `String(localized:)` with English as key, translated into es, fr, de, ja,
  zh-Hans in `Lineform/Localizable.xcstrings`. Sidebar width does not grow.
- New `.swift` files are added to `Lineform.xcodeproj/project.pbxproj` by hand (objectVersion 56,
  no synced groups): PBXBuildFile `1F000001…<serial>`, PBXFileReference `1F000002…<serial>`, group
  child, Sources phase. Next free serial is `04CD`; take serials in order across tasks.
- Nothing wired in `applicationDidFinishLaunching` (the test host is the app).
- Never construct an `NSWindow` in default-plan tests.

## Review Focus

1. **The same sentence appears twice in a document.** Selecting the second one and stepping
   versions must change the second, never the first. → Task 2 test
   `testLocatePicksOccurrenceMatchingContext`.
2. **CRLF / BOM files.** Stepping a version in a Windows-authored or BOM'd file must leave every
   other byte, line ending and the BOM unchanged. → Task 2 test `testLocateInCRLFAndBOMText`, Task 6
   test `testExitEditPreservesCRLFAndBOM`.
3. **The file was edited elsewhere between sessions.** A passage whose text no longer exists is
   dropped, never "found" in a similar place and overwritten. → Task 3 test
   `testPassageWhoseTextIsGoneIsDropped`.
4. **Emoji / combining marks at the selection edges.** Add to History on a selection that splits an
   emoji must snap to whole characters and never trap. → Task 2 test
   `testClassifyAlignsToComposedCharacters`.
5. **One ⌘Z after leaving History mode** restores the document exactly as it was on entry, however
   many steps were taken. → Task 6 test `testCollapsedExitEditUndoesToEntryText`.

**Interfaces:**
- Produces (model, all `Codable, Equatable`):
  - `enum HistoryAuthor: String, Codable { case you, ai }`
  - `enum HistoryLevel: String, Codable, CaseIterable, Comparable { case paragraph, sentence, word }`
    — `allCases` order is display order; `<` means "larger" (paragraph < sentence < word);
    `var title: String` localized ("Paragraph", "Sentence", "Word").
  - `struct HistoryVersion { var text: String; var author: HistoryAuthor; var createdAt: Date }`
  - `struct HistoryPassage: Identifiable { let id: UUID; var level: HistoryLevel; var versions: [HistoryVersion]; var currentIndex: Int; var parentID: UUID?; var parentVersionIndex: Int?; var contextBefore: String; var contextAfter: String; var lastTouched: Date }`
  - `struct DocumentHistory { var passages: [HistoryPassage]; var isEmpty: Bool { passages.isEmpty } }`
- Produces (store):
  - `protocol PassageHistoryPersisting: AnyObject { func load(for url: URL) -> DocumentHistory; func save(_ history: DocumentHistory, for url: URL); func retarget(from old: URL, to new: URL); func prune(now: Date); func clearAll() }`
  - `final class FilePassageHistoryStore: PassageHistoryPersisting` — `init(directory: URL, fileExists: @escaping (URL) -> Bool = FileManager.default.fileExists(atPath:))`; `static func defaultDirectory(home: URL) -> URL` → `<Application Support>/Lineform/History`.
  - `final class NullPassageHistoryStore: PassageHistoryPersisting` for tests and untitled documents.
  - `static let staleInterval: TimeInterval = 30 * 24 * 60 * 60` on `FilePassageHistoryStore`.

Layout on disk: `index.json` = `[{ "id": UUID, "pathKey": FileIdentity.key(for:), "bookmark": Data? }]`
plus `<id>.json` = `DocumentHistory`. Saving an empty `DocumentHistory` deletes `<id>.json` and its
index entry (nothing stored unless something is kept). Writes are `.atomic`. A missing or corrupt
file loads as empty, never throws to the caller.

**Interfaces:**
- Consumes: `HistoryLevel`, `HistoryPassage` (Task 1).
- Produces:
  - `enum PassageHistoryText`
  - `static func aligned(_ range: NSRange, in text: String) -> NSRange` — snaps to composed
    character boundaries (`rangeOfComposedCharacterSequences(for:)`) and trims surrounding
    whitespace and line endings.
  - `static func classify(_ range: NSRange, in text: String) -> HistoryLevel?` — after
    `aligned`: **word** = within one sentence and at most 3 words; **sentence** = within one
    paragraph (blank-line-separated block, using `markdownSourceLines`) but not the whole
    paragraph; **paragraph** = an entire paragraph, or spans more than one. `nil` for an empty range
    or a range that is only whitespace.
  - `static let contextLength = 32`

  - `static func locate(_ needle: String, before: String, after: String, in text: String, within scope: NSRange) -> NSRange?`
    — every occurrence of `needle` inside `scope`; choose the one whose surrounding text has the
    longest common suffix with `before` plus longest common prefix with `after`; return `nil` if
    there are no occurrences, or if two occurrences tie and both score 0.

### Task 3: Document history engine

**Files:**
- Create: `Lineform/Documents/DocumentHistoryEngine.swift`
- Test: `LineformTests/DocumentHistoryEngineTests.swift`

**Interfaces:**
- Consumes: Task 1 model, Task 2 `PassageHistoryText`.
- Produces — a value type with no UI or AppKit:
  - `struct LocatedPassage: Equatable { let id: UUID; let level: HistoryLevel; let range: NSRange; let rootID: UUID }`
  - `struct HistoryEdit: Equatable { let range: NSRange; let replacement: String }`
  - `struct DocumentHistoryEngine { var history: DocumentHistory; let now: () -> Date }`
  - `mutating func locateAll(in text: String) -> [LocatedPassage]` — locates roots in the whole
    text, children inside their parent's range; only children whose
    `parentVersionIndex == parent.currentIndex` are located; passages that cannot be located are
    **removed** together with their descendants (spec §5.1 rule 2); refreshes each located passage's
    `versions[currentIndex].text` from the live text and its context strings (spec §5.0: current
    version = live text).
  - `func canAdd(_ range: NSRange, in text: String) -> Bool` — `classify` non-nil, and the level is
    strictly smaller than the innermost located passage containing it (if any). False inside a
    `.word` passage (three-level cap).
  - `mutating func add(_ range: NSRange, author: HistoryAuthor, in text: String) -> UUID?` — if
    `range` equals an existing located passage's range, append a frozen copy of the live text as a
    new version (current index moves to the new, live version); otherwise create a passage with
    `versions = [copy(you), live(author)]`, `currentIndex = 1`, parent = innermost containing
    passage. Collapses consecutive duplicate versions. Updates `lastTouched`.
  - `mutating func recordAccepted(range: NSRange, original: String, accepted: String, in text: String) -> UUID?`
    — for plan 3: creates/extends a passage with versions `[original(you), accepted(ai)]`.
  - `mutating func step(_ id: UUID, by delta: Int, in text: String) -> HistoryEdit?` and
    `mutating func select(_ id: UUID, version index: Int, in text: String) -> HistoryEdit?` — wrap
    around; `nil` when the passage has one version or cannot be located.
  - `mutating func deleteVersion(_ id: UUID, at index: Int, in text: String) -> HistoryEdit?` —
    deleting the current version first switches to the neighbour (returns that edit); a passage left
    with one version is removed with its descendants.
  - `func group(containing id: UUID) -> [HistoryLevel]` — every level present in the passage's
    whole nested group (root plus all descendants for the root's current version), in
    `HistoryLevel.allCases` order.
  - `func chain(to id: UUID) -> [UUID]` — root … id.
  - `func descend(from id: UUID, to level: HistoryLevel) -> UUID?` — first nested passage of that
    level under `id` (current versions only).

Behaviour:
- Context menu: "Add to History" appears when the selection is non-empty and
  `historyCanAddHandler?(selectedRange) == true`, for `.markdown` and plain text alike; target
  `self`, sends `.add(selectedRange)`. Keep `menu.identifier = MainMenuIconDecorator.excludedMenuIdentifier`.
- When `historyDisplay != nil`:
  - Drawing: unchanged text is drawn with `recededInk` via a layout-manager temporary
    `.foregroundColor` over the visible range minus passage ranges; passages get `tint`, the hovered
    one `hoverTint`, the selected one `selectionTint` (selected wins), filled with
    `rectsForCharacterRange` in `drawBackground` and limited to the visible range. Dots: `count`
    5pt circles, 3pt gap, 0.75pt stroke, current filled, drawn at the selected passage's first
    glyph, top edge 0.32 × line height below that line's baseline area (clear of descenders). All
    temporary attributes are removed when `historyDisplay` becomes `nil`.
  - Input: `mouseDown` on a passage sends `.select(innermost id)` and does not call `super` (no
    caret move); on unchanged text it does nothing. Mouse moved sets `hoveredID` through the
    handler-free path (redraw only). `doCommand(by:)`: `moveLeft:`/`moveRight:` → `.step(-1/+1)`;
    `moveUp:`/`moveDown:` → `.moveSelection(-1/+1)` (keyboard path between passages);
    `cancelOperation:` → `.exit`. Hook `doCommand(by:)`, never `keyDown` (repo invariant).
  - Typing: `shouldChangeText` sends `.typedWhileInHistoryMode` first (the container exits History
    mode synchronously), then proceeds normally — the keystroke types.
  - Accessibility: post `NSAccessibility.post(element:notification:.announcementRequested)` with
    "<Level>, version <n> of <m>" on selection or step; never override the text view's AX value.
- Never put SwiftUI accessibility modifiers on `MarkdownTextViewRepresentable` (repo invariant).

  exit **without** applying the collapse, since the disk text replaces everything).
- When `hasHistory` becomes false while in History mode (last version deleted), exit and return the
  sidebar to the tab that was showing before History.
- Save to the store after every change that alters `history` (add, delete, step, exit). Never at
  launch; first store access happens in `open(url:text:)`, which also calls `store.prune(now:)` at
  most once per app session.
- `fileMoved` is called from `onExternalMove`, sidebar rename, and Save As (compare the old
  `currentFileURL` with the new one in `noteSavedToReloadWatcher`).
- Sidebar "History" row: `OutlineSidebarView` receives `hasHistory`; selecting `.history` calls
  `enterHistoryMode`; selecting any other tab calls `exitHistoryMode`.
- History mode lives in Write mode (spec §4.2 "Where it runs"): entering it from Read or Split
