What's New in Lineform 1.4.0

A fix release. No new features — this is a deep pass over how Lineform handles your files, with a focus on the ways a document could be quietly changed under you.

  • Live reload keeps working. A document only picked up the first external change to its file. If a coding agent or another editor kept writing, Lineform showed a stale copy from then on — and kept saving that stale copy. It now follows every change.
  • Windows-authored files stay byte-for-byte intact. A file saved with a byte-order mark (Notepad's default) lost it the first time you typed. Line endings and the mark are now preserved exactly as you received them.
  • Convert to Plain Text no longer damages code. It was removing one backslash from every escaped character inside fenced code blocks, so a regular expression or a Windows path came out wrong — and saved that way. Code blocks are now left exactly as written.
  • Find & Replace stops when it's done. Replacing a word with something containing it — log → logs — used to start replacing its own output, growing the text with every click. It now replaces each match once.
  • Two crashes fixed. Pressing Return on a line beginning with a very long number, and opening a document with a Mermaid pie chart containing an enormous value.
  • Mermaid diagrams with a title or config header now render instead of showing their source with a "Report this" link. Very large diagrams fall back to their source rather than making the window unresponsive.
  • Printing respects the paper size you pick. Changing Paper Size or Orientation in the print dialog now rewraps the text; it used to slice each line and spill the remainder onto extra pages.
  • Better exports. Inline $…$ math is now included in HTML export, matching how block math already worked. Escaped characters like \* render correctly on lines that also contain math.
  • Files sidebar. Turning off Show Hidden Folders no longer hides ordinary Markdown files in large folders, renaming your workspace folder in Finder no longer stops the sidebar from refreshing, and the Sort label now matches the order files are actually in.
  • Read aloud stops when you switch to another document, and starting, pausing, or resuming it in quick succession no longer leaves it stuck.
  • Accessibility. Link text now meets WCAG AA contrast on every reading theme, and VoiceOver no longer repeats the search status every time you pause typing.
  • Also: the copy button on a code block now copies the whole block in Windows-authored files, Markdown previews in Finder match what the app draws in several more cases, and lineform - now rejects non-text input at the pipe instead of failing later.
