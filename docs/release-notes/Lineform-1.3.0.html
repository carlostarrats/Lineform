What's New in Lineform 1.3.0

  • Document tabs — keep several files open in one window and switch between them without losing your place.
  • Images in Read and Preview — local images now render inline instead of showing a placeholder, and they appear in Styled PDF and print output. If an image has moved, a Reconnect button relinks it.
  • Syntax highlighting in code blocks, with a hover button to copy a block's contents.
  • Callouts — > [!NOTE], [!TIP], [!IMPORTANT], [!WARNING], and [!CAUTION] blocks render with their own title row.
  • Jump to File (⌘K) — fuzzy-search your workspace and open any file instantly.
  • Search across every file — the new All Files scope shows matching lines from your whole workspace, and clicking a result opens that file.
  • Read aloud — Edit ▸ Speech reads the document (or your selection) out loud.
  • Export As ▸ Rich Text, plus a style picker for PDF export and printing.
  • Markdown previews in Finder — press Space on a .md file to see it rendered the way Lineform renders it.
  • Shortcuts support — New Note and Open in Lineform are now available to Shortcuts, Spotlight, and Siri.
  • ⌘E toggles between Write and Read, and your scroll position carries across the switch.
  • Pie charts in Mermaid diagrams, and unsupported diagram types now fail cleanly instead of rendering nonsense.
  • A redesigned tab bar and window chrome that follow your reading theme in both light and dark mode.
  • Fixes: closed two Save As paths that could lose work, a file can no longer be open in two windows at once, switching to a tab whose file changed on disk now reloads it instead of showing a stale copy, and text no longer jumps while you resize the window.
